# Европа: Стратегия (Godot 4, Android)

Этапы: 1 меню и настройки; 2 карта Европы; 3 данные стран, выбор, время, сохранения; 4 пиксельный захват и война; 5 экономика (вкладки: обзор, налоги, расходы, финансы) и отдельное окно строительства.

## Запуск
1. Установи Godot 4.2+ (godotengine.org; есть редактор для Android).
2. Открой папку проекта (файл project.godot).
3. Нажми Play. Откроется загрузка, затем меню.

## Данные карты
Исходные границы: `tools/ne_50m_admin_0_countries.geojson` (Natural Earth).
Готовая карта для игры: `data/europe_map.dat`. Пересборка: `python3 tools/build_map.py`.

## Сборка APK
Проект → Экспорт → «Android APK (тест)» → Экспортировать проект.
Для AAB: Проект → Установить шаблон сборки Android, затем пресет «Android AAB»
и своё release-хранилище ключей (keystore).
Пакет: com.europestrategy.game (можно поменять до публикации).

## Структура
scenes/ — сцены; scripts/core — настройки и сохранения; scripts/ui — интерфейс;
остальные папки в scripts/ — модули будущих этапов.

## Области
Деление стран на области: `tools/regions_map.jpg` (картинка с областями) -> `python3 tools/build_regions.py`
-> `data/europe_regions.dat`. Картинка в проекции LAEA, параметры подобраны по береговой линии.
Нужны numpy, scipy, opencv-python. Названий областей пока нет (только номера).

## Армия и режим фронта
Кнопка «Армия»: призыв, обучение и вооружение влияют на силу в войне.
Во время войны появляется кнопка «Фронт»: синие точки ваши войска, красные противника, кольца армии позади, жёлтые точки областные центры.

## Автоматическая сборка APK через GitHub Actions

1. Загрузи содержимое этой папки проекта в свой GitHub-репозиторий (ветка `main` или `master`).
2. Открой вкладку **Actions** в репозитории.
3. Выбери **Build Android APK** и нажми **Run workflow**.
4. После успешной сборки открой завершённый запуск и скачай файл из **Artifacts** — `europe-strategy-android-apk`.

Сборка использует существующий пресет `Android APK (тест)` и не меняет игровые сцены или скрипты.
